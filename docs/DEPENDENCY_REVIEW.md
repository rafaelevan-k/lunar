## Fidelity experiment and approved deferred deadline

Sprint 0 discovery was closed by the user on 2026-10-27 under [accepted ADR-0005](ADR/ADR-0005-sprint-0-validation-deferral.md). The incomplete DOCX renderer/reference comparison below remains unverified and must complete before enabling/promising BE-25/BE-27/FE-20–22 DOCX rendering and relevant Sprint 6 acceptance. Missing LibreOffice remains DependencyUnavailable; Word remains reference-only. Native redistribution clearance and WiX terms/signing remain unchanged later holds. [Closure approval](evidence/sprint-0/closure-20261027/APPROVAL.md).

Use only synthetic fixtures: alpha PNG, rotated EXIF JPEG, PDF with text/vector/transparency and multiple pages, DOCX with headings/table/page break/images and known installed fonts. Record generator, hashes and renderer versions. Render at 150 DPI, compare page count, geometry, font substitution, transparency, orientation and output visual quality. Repeat at 300 DPI for resource cost. Compare DOCX against a Word-rendered reference where a licensed environment is available.

Current result: synthetic PNG/JPEG/PDF and DOCX embedding experiments executed with scoped PASS; four PDF rasters visually reviewed. DOCX rendering/independent renderer comparison remains NOT_RUN: the isolated Word reference export timed out at 60 seconds, no reference PDF was produced, and the owned process was cleaned up. No DOCX fidelity score or complete golden corpus is claimed. See CONVERTER_DISCOVERY for exact successful and failed evidence.

2026-10-27 technical continuation: no dependency/version change; locked restore and all three Windows Release builds pass. OS bitmap re-encoding demonstrates DPI normalization for synthetic sRGB rasters, with no pixel changes. [Microsoft's API documentation](https://learn.microsoft.com/en-us/uwp/api/windows.graphics.imaging.bitmapencoder.setpixeldata) confirms explicit DPI parameters and sRGB semantics; arbitrary ICC preservation remains unverified. Word reference opens/counts pages but times out at PDF export; no independent rendering comparison. [LibreOffice's license page](https://www.libreoffice.org/licenses/) was rechecked: MPL 2.0 plus version-specific components; no download/install/bundling or redistribution clearance occurred. Existing native/WiX holds stay intact. [Current evidence](SPIKE_RESULTS.md#completion-attempt--2026-10-27).
