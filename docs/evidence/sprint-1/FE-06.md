## Limitations

- State indicators, Settings and Start with Windows are deferred (above). FE-06's acceptance does not require them to work, but its objective names them.
- No single-instance guard (BE-05): two launches mean two pills and two icons. (Resolved later the same day by BE-05; see its evidence.)
- A crash or kill can leave a ghost icon until the mouse passes over it (normal Windows behavior).
- `OpenForKeyboard` focus handoff and its return to non-activating were not exercised by an automated test (activation depends on the foreground-lock state of the session); manual item 4 covers it.
- `UseWindowsForms` is a new framework reference for Desktop (in-box, no package); WinForms is used only for `NotifyIcon`. Alternative (hand-written `Shell_NotifyIcon` P/Invoke) was rejected as more native code in Desktop than ADR-0007 allows. No ADR written; reverse by replacing the class.
- Taskbar-position, high-contrast tray icon, DPI scaling of the icon and Windows 10 22H2 are NOT_RUN.
