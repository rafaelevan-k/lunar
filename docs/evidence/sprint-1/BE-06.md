## Acceptance

| Criterion | Evidence |
|---|---|
| Persist versioned settings to LocalAppData | `schemaVersion: 1` file at `%LocalAppData%\Lunar\settings.json`, UTF-8 without BOM; round-trip of every field; real-host run above. |
| Atomic writes and backup | Temp file + flush + `File.Replace` with `.bak`; second save keeps the previous file as backup; a locked temp file makes the save fail with the old file intact; saving over a corrupt file leaves the last good backup untouched; 25 concurrent saves leave a valid file and no temp file. |
| Validation and defaults | Rules tests; per-field repair keeps valid siblings; wrong types, out-of-range offset, bad theme (including numeric strings), bad locale, relative/UNC/device output folders → `ValuesReset`; missing fields and explicit nulls → defaults with no notice. |
| Corrupt settings recover without crashing | 12 corrupt contents (empty, whitespace, text, truncated, `[]`, `42`, `null`, `{}`, version 0, version as string, trailing text, binary), oversize file, depth-bomb → `ResetToDefaults` with the file kept as `settings.corrupt.json`; corrupt main + good backup → `RestoredFromBackup`; main missing + backup → `RestoredFromBackup`. |
| Tests for migration | `SettingsMigrationTests` (invalid/missing/non-integer versions, newer, ordered chain, start from the file's version, idempotence, missing step, throwing step) and repository tests with a two-version chain (old file migrated, persisted as v2, original kept as backup, second load unchanged; failing step recovered like a corrupt file). |
| Newer-version safety | A v2 file is neither read nor rewritten; load gives defaults with `NewerVersionIgnored`, save returns `Unsupported`, bytes unchanged, no backup or corrupt copy created. |
| Privacy | Log events carry the `Settings` component, fixed ids and error codes only; a test checks that no value, path fragment or the settings folder appears in any event. |

## Open items

- **No production migration exists.** v1 is the first schema, so the migration path is proven only with test steps. The first breaking change must add a step and a fixture from the real previous format.
- Not verified: power loss between flush and replace, a redirected or network `%LocalAppData%`, antivirus holding the file, Windows 10 22H2. A locked file is covered (it fails and leaves the file alone).
- Settings are not used by the app yet. `App` does not load them; the `LUNAR_DIAGNOSTICS=1` switch stays until a consumer reads `privacy.diagnosticsEnabled` (FE-23 or a later wiring change; `docs/PRIVACY.md` is updated then). The tray's Settings and Start with Windows items remain disabled (FE-23/BE-29).
- There are no change events; consumers reload through `LoadAsync`.
- The output folder check accepts any absolute local path syntax; whether the folder exists or is writable is the converter's concern (BE-19+).
- Tracking: FE-05 is the first expected consumer (`island.preferredMonitorId`, `island.topOffsetDip`).
