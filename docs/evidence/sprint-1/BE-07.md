## Limitations

- Logs carry no messages, so diagnosis relies on event IDs, error codes and durations; richer events need new reviewed IDs.
- The environment variable is a tester switch; the user-facing setting waits for BE-06/FE-23. No log export exists.
- Retention across multiple days and behavior on a full disk, antivirus locks and read-only profiles (other than the unit-tested unusable-directory case) NOT_RUN.
- Logging is synchronous and unbuffered; no measurement of its cost was made (events are few).
- `Trace` is still used before the log exists and when startup fails before the container is built.
- Other adapters and Desktop code could still call `Trace`/`Console` directly; a lint rule is not in place. Features that arrive later must define their own event IDs and be reviewed against PRIVACY.md.
- `docs/PRIVACY.md` is a development description, not the final user notice (Sprint 7).
- Tray, window and activation behavior is unchanged except for the extra log lines.
